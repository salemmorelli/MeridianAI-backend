MeridianAI is an application that serves to help users who desire to use alternative health techniques such as Acupressure from TCM (Traditional Chinese Medicine) to solve various health ailments.

The application uses an intelligent ai system to learn from and guide the user into specific acupressure points that can help with whatever they are experiencing. 

The system currently uses the Random Forest Classifier model in python to help match the users symtoms to an acupressure point based on the WHO acupressure nomenclenture guide (https://www.who.int/publications/i/item/9290611057).

Other Features:-
- NLP - Natural language symptom parsing via LLM integration (Claude API)
- Feature preprocessing — OneHotEncoding via ColumnTransformer
